# サブプロジェクト3a「CMSの土台と記事編集」Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `/admin` から実績・コラム・お知らせ・固定ページを作成・編集・公開/下書き・ゴミ箱・履歴復元できる（日英対応、Cloudflare Access認証、HTML無害化）。

**Architecture:** ロジックはすべて `D1Like`・`Request` を受け取る純粋モジュール（`src/admin/*`）に置き、vitest＋`node:sqlite` シムで検証する。Astroのルートは薄い入口。WYSIWYGは Tiptap をクライアント島としてビルドに同梱。

**Tech Stack:** Astro 7 SSR（Cloudflare）、D1、TypeScript、vitest、`xss`（HTML無害化）、Tiptap（`@tiptap/core` `@tiptap/starter-kit` `@tiptap/extension-link` `@tiptap/extension-image`）、WebCrypto（JWT検証）。

**Spec:** `docs/superpowers/specs/2026-10-15-cf-cms-3a-design.md`

## Global Constraints

- 公開サイトの既存URL・表示・テストは変えない（変更は本文表示の無害化のみ。実データで差分0を確認）。
- `/admin` 配下は **fail closed**: Access環境変数（`ACCESS_TEAM_DOMAIN` `ACCESS_AUD`）が空なら503。`DEV_ADMIN_EMAIL` によるバイパスは **ホストが `localhost`/`127.0.0.1` のときだけ**有効。
- 変更系API（POST/PUT/DELETE）は `Content-Type: application/json` 必須、`Origin` がリクエストURLのoriginと一致すること。
- 状態は `draft`/`publish`/`trash` のみ。削除は `trash` への変更（物理削除しない）。
- 新規記事の `wp_id` は `MAX(wp_id)+1`（最小1000）。スラッグは空白・`/` `?` `#` `%` を含まない1〜200字、`type`内で一意。空ならサーバーが `post-<base36時刻>` を生成。
- 時刻: クライアントは JST の `YYYY-MM-DDTHH:mm` を送り、サーバーがUTCの `YYYY-MM-DD HH:MM:SS` に変換して保存。
- 改版は更新・削除（trash）・復元の直前に保存し、記事ごと最新50件を保持。
- 無害化の許可タグ: `h1 h2 h3 h4 h5 h6 p br hr ul ol li blockquote pre code strong em u s a img figure figcaption table thead tbody tr th td iframe`（iframeは YouTube(`https://www.youtube-nocookie.com/embed/`)・Spotify(`https://open.spotify.com/embed/`)のみ）。許可属性: `href src alt title class width height target rel`（`iframe` は `src title width height loading allow allowfullscreen`）。`href/src` は `http(s)` `mailto` 相対(`/`)・`#` のみ。`target=_blank` には `rel="noopener"` を付与。`script` `style` は中身ごと削除、`on*` 属性は削除。
- 編集項目（メタ）: works=`client_name client_name_en period_start period_end role role_en scope tech_stack tech_stack_en site_url is_featured kpi_results kpi_results_en`、news=`media_youtube media_spotify`、全種別=`ssp_meta_title ssp_meta_description ssp_meta_image`。ターム: works=`works_type industry skill`、column=`skill`、news=`news_type`、page=なし。
- 本番ドメイン・GCP・DNSには触れない。確認用サイトにデプロイしてよいのは fail closed（503）を確認した場合のみ。
- テストコマンド: `npm --prefix cf-site test`。`bash -c` を含むコマンドは使わない。

## Review Focus

- 無害化の回避: `<img src=x onerror=…>`、`<a href="javascript:…">`、`<a href="JaVa\tScRiPt:…">`、`<svg onload>`、`<iframe src="https://evil">`、`<script>`、`<style>`、`<a target=_blank>` の `rel` 欠落、`<math>`、HTMLコメント内の `<script>`（Task 2）

- CSRF: `Origin` 無し/不一致、`text/plain` の変更系（Task 6）
- 楽観的ロック: 古い `expected_modified_at` で409、同時刻の二重保存（Task 5）
- スラッグ: 重複・空・日本語・`%`/`/` を含む・201字・予約語（`page` `new`）（Task 4）
- 公開側: ゴミ箱/下書きが公開クエリに出ない、改版が50件を超えたら古いものが消える（Task 5）

`d1.ts`:
```ts
export interface D1Stmt {
  all<T>(): Promise<{ results: T[] }>;
  first<T>(): Promise<T | null>;
  run(): Promise<{ meta: { changes: number; last_row_id: number } }>;
}
export interface D1Like {
  prepare(sql: string): { bind(...a: unknown[]): D1Stmt };
  batch(statements: D1Stmt[]): Promise<{ results: unknown[] }[]>;
}
```
`d1shim.ts`: `bind` が `{ all, first, run, __exec: () => result }` を返す。`run` は `stmt.run(...a)` の `{ changes, lastInsertRowid }` を `{ meta: { changes: Number(changes), last_row_id: Number(lastInsertRowid) } }` に変換。`batch` は `raw.exec("BEGIN")`→各stmtの `__exec()`→`COMMIT`、例外で `ROLLBACK` して再throw。

```ts
import { FilterXSS, getDefaultWhiteList } from "xss";

const TAGS = "h1 h2 h3 h4 h5 h6 p br hr ul ol li blockquote pre code strong em u s a img figure figcaption table thead tbody tr th td iframe".split(" ");
const COMMON = ["class"];
const wl: Record<string, string[]> = {};
for (const t of TAGS) wl[t] = [...COMMON];
wl.a = ["href", "title", "target", "rel", ...COMMON];
wl.img = ["src", "alt", "title", "width", "height", ...COMMON];
wl.iframe = ["src", "title", "width", "height", "loading", "allow", "allowfullscreen", ...COMMON];
wl.td = ["colspan", "rowspan", ...COMMON]; wl.th = ["colspan", "rowspan", ...COMMON];

const URL_OK = /^(?:https?:\/\/|mailto:|\/(?!\/)|#)/i;
const EMBED_OK = /^https:\/\/(?:www\.youtube-nocookie\.com\/embed\/|open\.spotify\.com\/embed\/)/;
const clean = (v: string) => v.replace(/[\u0000-   ᠎ -  　﻿]/g, "");

const filter = new FilterXSS({
  whiteList: wl,
  stripIgnoreTag: true,
  stripIgnoreTagBody: ["script", "style"],
  allowCommentTag: false,
  onTag(tag, html, opts) {
    if (tag === "iframe" && !opts.isClosing) {
      const src = /\ssrc="([^"]*)"/i.exec(html)?.[1] ?? "";
      if (!EMBED_OK.test(src)) return "";
    }
    if (tag === "iframe" && opts.isClosing) return undefined;
    if (tag === "a" && !opts.isClosing && /\starget="_blank"/i.test(html) && !/\srel=/i.test(html)) {
      return html.replace(/\starget="_blank"/i, ' target="_blank" rel="noopener"');
    }
    return undefined;
  },
  safeAttrValue(tag, name, value, css) {
    if (name === "href" || name === "src") {
      const v = value.trim();
      if (!URL_OK.test(v) || /^(?:javascript|data|vbscript):/i.test(clean(v))) return "";
      return v.replace(/"/g, "&quot;");
    }
    return filter.safeAttrValue(tag, name, value, css);
  },
});

export function sanitizeHtml(html: string): string {
  return typeof html === "string" && html ? filter.process(html) : "";
}
```

```ts
export interface AccessConfig { teamDomain: string; aud: string; adminEmails?: string[] }
export interface Jwks { keys: (JsonWebKey & { kid: string })[] }
const fail = (m: string): never => { throw new Error(`access: ${m}`); };
const dec = (s: string) => Uint8Array.from(Buffer.from(s, "base64url"));
const json = (s: string) => JSON.parse(new TextDecoder().decode(dec(s)));

export async function verifyAccessJwt(token: string, cfg: AccessConfig, getJwks: () => Promise<Jwks>, nowSec = Math.floor(Date.now() / 1000)): Promise<{ email: string }> {
  const parts = token.split(".");
  if (parts.length !== 3 || !parts[2]) return fail("malformed");
  let header: any, payload: any;
  try { header = json(parts[0]); payload = json(parts[1]); } catch { return fail("malformed"); }
  if (header.alg !== "RS256") return fail("alg");
  const jwk = (await getJwks()).keys.find((k) => k.kid === header.kid);
  if (!jwk) return fail("kid");
  const key = await crypto.subtle.importKey("jwk", jwk, { name: "RSASSA-PKCS1-v1_5", hash: "SHA-256" }, false, ["verify"]);
  const ok = await crypto.subtle.verify("RSASSA-PKCS1-v1_5", key, dec(parts[2]), new TextEncoder().encode(`${parts[0]}.${parts[1]}`));
  if (!ok) return fail("signature");
  if (payload.iss !== `https://${cfg.teamDomain}`) return fail("iss");
  const aud = Array.isArray(payload.aud) ? payload.aud : [payload.aud];
  if (!aud.includes(cfg.aud)) return fail("aud");
  if (typeof payload.exp !== "number" || payload.exp <= nowSec) return fail("exp");
  if (typeof payload.nbf === "number" && payload.nbf > nowSec) return fail("nbf");
  if (typeof payload.email !== "string" || !payload.email) return fail("email");
  return { email: payload.email };
}
```
